Valid Anagram:

- we can convert both strings to char Arrays and then check if each element of first array is present in second array. If not present, then return false. But, this would check 
  only the presence but not the frequency.
- So, use a HashMap to store the character and count of each char in both the arrays. (This approach makes use of .getOrDefault(), .put(), .get() methods of HashMap)
  O(n) time and O(n) space (we create new array to store the freq)

Container with most water:

- We calculate the area for every occurrence of l and r (width = l-r and height = Math.min(height[l], height[r])).
- And for every occurrence, set a value for maxArea (Math.max(maxArea, area)). And, we do this setting inside while loop. If we do it outside while loop, then we will get only the area of last entry of l and r.

leftMax[0] = height[0];

Top K frequent elements:

- Use HashMap to count the frequency of elements.
- Use a min heap to keep the top k frequent elements.
- remove the least frequent from the heap size when size > k



Basic pattern in optimization problems:
- While looping through options, track the best result seen so far.
You’ll see this in:
- Maximum subarray problems (Kadane’s)
- Best time to buy and sell stock
- Longest substring without repeating characters
- Max sliding window problems


When to use a HashMap:

- When there is a need to group elements based on some derived key
- when we want to check for existence or retrieve a group by some property
- when the problem has lookup, counting or clustering.


Use Map<key, List<value>> when we have multiple values for a unique key.
