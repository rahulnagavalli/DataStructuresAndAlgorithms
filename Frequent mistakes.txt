Frequent Mistakes: 
- checking code line by line after writing
- put semi-colons (;) at the end of lines
- put correct indentation
- return statements
- Basic methods for data types (like, String.toCharArray, String.charAt(i), Character.toLowerCase(), Character.isLetterOrDigit())
- look for data type overflows (like, int overflow for large integers. In that case, convert the sum into long - like in 4Sum problem)
