Generics don’t work with primitive data types. They work with custom classes and Wrapper classes.
Also, using Object as generic type doesn’t work and it would cause type safety issues. 
So, it would be better to use generics with angle brackets. Like, <T>


Public class Printer<T extends Animal>

Here, above format is called as “Bounded generic”.

- If you want to add Generics to methods, below is the syntax:

Public static <T> void shout(T thingToShout) {
	System.out.println(thingToShout + “!!”);
}

Here, “T” is the generic type. 
And, we have to mention the generic type in angle brackets before method’s return type. 
Like “<T>”.

We can also have multiple generic types. Like, below:
Public <T, V> void shout(T firstThing, V secondThing) {

}

We can also return a generic type. Like, below: 

Public <T, V> T shout(T firstThing, V secondThing) {

}

Stack: 
	It is an Abstract, Linear data type with a pre-defined capacity.
	It specifies the operation and behaviour without specifying how the data is stored or implemented.

	Stacks are great for processing nested structures, and are important for understanding Recursion.
	Important: Insertion and Deletion happens at the same end in a Stack (top end)

	Real-life uses: Undo, Redo function in any text editor.

	Methods: 
	pop: removes element from the Stack
	push: adds element to the Stack
	empty(): Returns true when a Stack is empty
	peek(): Returns value of the top element 
	search(Object obj): Checks whether the given obj is present in Stack and if yes, returns its position from the top of the Stack. Otherwise, it returns "-1"
