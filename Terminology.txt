Abstract: 
  Defines what can be done and not how.
  Eg: Stack -> It is considered as a Abstract data type. Because, it defines what operations can be performed. But it doesn't define how those operations can be done. Those operations can be done by ArrayList, LinkedList etc. 
  Analogy: Blueprint -> It defines what the building should have (doors, windows etc.)
           Building -> It defines how it's built.

Abstract data type: 
  It focuses on what operations can be performed - it is conceptual. 
  Eg: Stack, Queue, Map etc. 

Data structure: 
  It focuses on how the data is actually stored and organized - it is about the implementation.
  Eg: ArrayList, LinkedList, HashMap etc. 

Linear data type: 
  Data elements are arranged sequentially - one after another. 
  Eg: Stack, Queue, LinkedList

Non-Linear data type: 
  Elements branch out.
  Eg: Tree, Graph

Idempotency: 
  Performing a same request multiple times has the same effect as performing it once. End state doesn't change. 

Rate limiting: 
  It is a control mechanism that limits the number of operations that a client can perform within a given time period.

SubString: 
  A contiguous and non-empty sequence of characters.

Stack: 
  It is an Abstract data type, which can be implemented using different data structures such as ArrayList or LinkedList.
