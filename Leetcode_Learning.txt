- there has to be a way to avoid duplication.

Sliding window:
- As we are moving j to expand the window, if we find a duplicate character, moving i forward until the window becomes valid again.

This can be achieved using HashSet and HashMap.

Key Idea: Sliding Window

Instead of starting over for every i, we can use two pointers (left and right) and a HashSet (or HashMap).

right moves forward exploring characters.

If s[right] is unique, include it and update answer.

If s[right] is duplicate, move left forward until duplicate is removed.

This way, each character is processed at most twice (once added, once removed).

👉 Complexity becomes O(n).

Longest Substring with At Most Two Distinct Characters: 
  as the problem statement is about finding substring with at most 2 distinct characters, we need to keep a count of distinct characters and store the characters as well. So take Map
  as this is a sliding window, first expand the window. And if the window becomes invalid (if (map.size() > 2), then shrink from the left. Instead of if, take while loop. Because, we have to continue shrinking to get        valid subString.

class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int l = 0; 
        int r = 0;
        int maxLen = 0;
        while (r < s.length()) {
            char c= s.charAt(r);
            map.put(c, getOrDefault(c, 0) + 1);

            while (map.size() > 2) {
                char leftChar = s.charAt(l);
                map.put(leftChar, map.get(c) - 1);
                if (map.get(leftChar) == 0) {
                    map.remove(leftChar);
                }
                l++;
            }
            maxLen = Math.max(maxLen, r - l + 1);
            r++;
        }
        return maxLen;
    }
}

reason of checking whether map.get(leftChar) == 0. 
  After shrinking the window, a character's count can become zero, but the key still remains in the Map. If that is the case, map.size() will not decrease even though that character is no longer in the window.
  map.size() must reflect number of distinct characters in the window.
