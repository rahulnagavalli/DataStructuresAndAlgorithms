Sliding window:
- As we are moving j to expand the window, if we find a duplicate character, moving i forward until the window becomes valid again.

This can be achieved using HashSet and HashMap.

Key Idea: Sliding Window

Instead of starting over for every i, we can use two pointers (left and right) and a HashSet (or HashMap).

right moves forward exploring characters.

If s[right] is unique, include it and update answer.

If s[right] is duplicate, move left forward until duplicate is removed.

This way, each character is processed at most twice (once added, once removed).

👉 Complexity becomes O(n).

  Q: In the first comparison (nums[j] vs nums[i-2]), we don’t write anything. So how do we even arrive at the idea of doing nums[i] = nums[j] later?
  A: As we have to keep valid numbers on the start of the array, we have to read values from the right side using j and write values into the left side using i. 
    Eg: if input array is 1,1,1,2,2,3. here, nums[2] == nums[0]. So, we don't want to write elements from right onto the left.

  Q: Why use nums[i] = nums[j]? 
  A: We want to move the next element (jth index) to i (which is the variable holding next position of valid element).

Longest Substring with At Most Two Distinct Characters: 
  as the problem statement is about finding substring with at most 2 distinct characters, we need to keep a count of distinct characters and store the characters as well. So take Map
  as this is a sliding window, first expand the window. And if the window becomes invalid (if (map.size() > 2), then shrink from the left. Instead of if, take while loop. Because, we have to continue shrinking to get        valid subString.

class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int l = 0; 
        int r = 0;
        int maxLen = 0;
        while (r < s.length()) {
            char c= s.charAt(r);
            map.put(c, getOrDefault(c, 0) + 1);

            while (map.size() > 2) {
                char leftChar = s.charAt(l);
                map.put(leftChar, map.get(c) - 1);
                if (map.get(leftChar) == 0) {
                    map.remove(leftChar);
                }
                l++;
            }
            maxLen = Math.max(maxLen, r - l + 1);
            r++;
        }
        return maxLen;
    }
}

reason of checking whether map.get(leftChar) == 0. 
  After shrinking the window, a character's count can become zero, but the key still remains in the Map. If that is the case, map.size() will not decrease even though that character is no longer in the window.
  map.size() must reflect number of distinct characters in the window.

  Find the array index corresponding to this character and increment its frequency:

  class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int k = s1.length();
        if (k > s2.length()) return false;

        int[] target = new int[26];
        int[] window = new int[26];

        for (int i = 0; i < k; i++) {
            target[s1.charAt(i) - 'a']++;
            window[s2.charAt(i) - 'a']++;
        }

        if (matches(target, window)) return true;

        for (int r = k; r < s2.length(); r++) {
            window[s2.charAt(r) - 'a']++;         // add new char
            window[s2.charAt(r - k) - 'a']--;     // remove old char

            if (matches(target, window)) return true;
        }

        return false;
    }

    private boolean matches(int[] a, int[] b) {
        for (int i = 0; i < 26; i++) {
            if (a[i] != b[i]) return false;
        }
        return true;
    }
}

Reverse linked list:

  Iteratively:
    Choose 3 pointers. prev, current and head.
    We need to adjust the arrows to point backwards, starting from the head node, because we cannot go back in a linked list.
    To point the head node (or current node in this case) backwards, point it to previous node. (create a previous dummy node setting its value to null).
    In every iteration, set current node to point to previous. And, save the next node by setting it to a dummy variable.
    Move current node to next node in the front.
    NOTE: current.next need not be only in forward direction. It just refers to the pointer/reference. This is important to note in this problem.
    next, move both the prev and current pointers one step ahead (prev = current; current = temp)

  Recursively: 

    Approach to follow: 
      Recurse first, fix arrows on the way back.
      Dive all the way to the last node and fix the arrows on the way back.

    Consider two people walking in a circle. They would meet one another only when one is moving slower than the other.

    Two pointer approach:
      Take 2 pointers - a slow pointer and a fast pointer to start from first node. 
      Slow pointer moves one node at a time and fast pointer moves two nodes. 
      If they meet at any point, a cycle exists. 
      If fast pointer reaches null, no cycle exists - we check that by using fast != null (this handles the case where fast lands on null) && fast.next != null (this handles the case where fast lands on last but one
      element - before null)

        Straightforward approach is to find the length of the given linked list in one pass and then remove the node in second pass.

IMPORTANT: 
  We use fast != null in the while loop condition when we want to evaluate code until fast is null
  When fast is null, loop exists. 
  Usage: If you don't need fast and only care about 'slow', then use 'fast != null'.

  If you need to read or use 'fast' after the loop, use 'fast.next != null'. 
  Because, loop exits when fast.next is null, that means fast is the last node of the given linked list.

  If you want to process every node, then use cur != null in while loop condition. 
  If you want to stop at the last non-null node, then use cur.next != null in while loop condition.

division or row number: It gives how many complete groups of n come before this index (where n is the number of elements in a row or also referred as number of columns)
modulo or column number: It gives the position of the index in the current row

0 1 2 3

slowest that koko can eat bananas is 1 banana per hour.
fastest that she can eat is size of the largest pile - because eating faster than that doesn't help as she can only eat one pile per hour.

so possible speeds: 1,2,3,..... max(piles)

if k is too slow, any speed lesser than k is also too slow.
